# Domino's Bangladesh — Website Redesign Concept

Unofficial portfolio concept. Not affiliated with Domino's. Ordering, checkout and email sign-up are demo-only.

Single-file static site (`index.html`), no build step.

## Deploy
- **Vercel:** Import repo → Project Name in lowercase (e.g. `dominos-redesign`) → Framework Preset **Other**, Build Command empty, Output Directory `.`.
- **GitHub Pages:** Settings → Pages → branch `main`, folder `/ (root)`.
